## Ground truth / gotchas (from MVP investigation)
- Repos: git **toplevel** is the workarea (e.g. `…/JNC_2`), files tracked as `core/fe/...`;
  blame accepts cwd-relative paths. Default JNC = `…/bak_latest_turnins/jnc/fit/fit-jnc-a0-master-latest`.
- Commit messages carry **HSD ids** (`\d{9,14}`) and **turnin ids** (`user_turnin<N>`).
- IDSID mapping: `.idsid_cache.json` + phonebook (see `resolve_identities`, mirrored from teamhub).
- HSD-ES: reachable, **needs auth** (302). GitHub restricted repo: **403 SAML SSO**.
- Live server: `JNC_REPO=… GFC_REPO=… bin/codelens` → http://<host-ip>:8770.
