Methodology

How completion is calculated

Active completion is complete ÷ (complete + open). Items marked future or rejected remain visible but are excluded from the active denominator, matching the filtering semantics used by the internal coverage tooling.

Item-type inclusion is scoped independently: project selections recalculate the project dashboard, while each plan overview keeps its own browser-saved selection.

Completion targets are shared and persisted by the ValTrak service. Plans inherit the portfolio target unless they define their own, and validation-plan sections inherit their plan target. The displayed gap is the number of additional complete active items needed to reach the target, rounded up to the next whole item.

The dashboard reflects validation-plan workflow status (i_status), not measured test or coverage grade. The queried aggregate plan did not expose populated grade values in this snapshot. Project totals are reference-weighted: when a plan is referenced more than once by the aggregate, each reference instance contributes to project scope. The plan detail identifies these cases explicitly.
